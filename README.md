# University Student Record and Campus Route Management System

## 1. Project Overview

The University Student Record and Campus Route Management System is a Java-based console application developed for the CIT300 Data Structures and Algorithms Graded Practical Assignment 1.

The system manages university student records and represents connections between campus locations using different data structures and algorithms. The project demonstrates the practical use of Linked Lists, Stacks, Queues, Binary Search Trees, Hashing, Graphs, and Breadth-First Search (BFS).

The application provides a menu-driven interface with 16 options for managing student records, service requests, recent actions, student searching, and campus routes.

## 2. Technologies Used

- Java
- GitHub
- Git
- Java Console Interface

## 3. Data Structures and Algorithms

The project implements the following:

- Singly Linked List – used to store and manage student records.
- Queue – used to manage student service requests using FIFO.
- Stack – used to store and display recent system actions using LIFO.
- Binary Search Tree (BST) – used to organize students by Student ID and display them in sorted order.
- Hash Table – used for efficient Student ID searching.
- Graph – used to represent campus locations and connections using an adjacency list.
- Breadth-First Search (BFS) – used to traverse connected campus locations.

## 4. Main System Features

- Add, update, delete, search, and display student records.
- Validate Student IDs and prevent duplicate records.
- Validate student marks.
- Add and process student service requests.
- Display recent system actions.
- Display students using BST traversal.
- Search students using hashing.
- Add and remove campus locations.
- Add and remove campus connections.
- Display campus connections.
- Traverse campus locations using BFS.
- Handle missing records and unavailable connections.
- Provide a menu-driven console interface.

The system contains all 16 required menu options specified in the assignment.
